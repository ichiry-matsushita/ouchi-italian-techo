# 原稿の置き場所

記事1本につきフォルダを1つ作り、原稿と写真を入れます。

```
drafts/
  2026-11-amatriciana/
    draft.txt   ← メモ書き程度の原稿（箇条書き・話し言葉でOK）
    01.jpg      ← 完成写真
    02.jpg      ← 手順の写真（あれば）
    03.jpg
```

- フォルダ名は `年-月-料理名（半角英字）`。料理名の部分が記事のURLになります（例：`/articles/amatriciana/`）。
- 写真はファイル名の番号順に、1枚目が完成写真、2枚目以降が手順の写真として使われます。
- 写真は JPG / PNG / WebP。iPhone の HEIC は JPG に書き出してから置いてください。
- 写真は記事に取り込むときに位置情報などが消されます。
  原稿フォルダの写真そのものは GitHub に上がらないよう、`.gitignore` で除外しています。

## 原稿に書いておくとよいこと

書いていないことは記事に `TODO:` として残り、あとで人が埋めることになります。

- 料理名、何人分か、調理時間
- 材料と分量（手に入りにくい食材なら、代わりになるもの）
- 作り方の流れ（火加減や目安の時間も）
- うまく作るコツ、失敗したこと
- 作ってみたきっかけ、発祥の地域（わかれば）

## 記事にする

```
/new-article drafts/2026-11-amatriciana
```
